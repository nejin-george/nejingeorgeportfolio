# Nejin George — Portfolio Website

## Files
- `index.html` — content and sections
- `style.css` — design, layout, and animations
- `script.js` — mobile menu, scroll progress, reveal animations

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

## Before publishing
1. In `index.html`, replace `your.email@example.com` with your actual professional email.
2. Replace the LinkedIn and GitHub placeholder URLs with your profile URLs.
3. Add your résumé PDF at `assets/nejin-george-resume.pdf` (create the `assets` folder if needed).
4. Add verified certificates and links.
5. Check every project description and remove any tools or claims that do not reflect your actual work.
6. Optionally add project repository links, screenshots, and dates.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository named `nejin-portfolio` (or another name you prefer).
3. Upload `index.html`, `style.css`, and `script.js` to the repository root. Upload the `assets` folder too if using a résumé.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait for deployment. GitHub will show your public URL, usually `https://YOUR-USERNAME.github.io/nejin-portfolio/`.
8. Test the website on mobile and desktop.

## Notes
- Hosting is free for public repositories on GitHub Pages.
- Google Fonts requires an internet connection; the site still uses fallback fonts if unavailable.
- Never upload private information, passwords, student ID numbers, or certificates containing sensitive data.
